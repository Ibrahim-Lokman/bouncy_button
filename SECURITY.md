# Security Policy

## Supported versions

Security fixes are released for the latest major version only.

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

## Reporting a vulnerability

Please don't report security issues in public issues, discussions, or pull requests.

Report them privately through GitHub instead:

1. Go to the [Security tab](https://github.com/Ibrahim-Lokman/bouncy_button/security) of this repository.
2. Select **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and which versions are affected.

Only the maintainer can see the report. You'll get a reply there, and the fix will be coordinated with you before details are made public.
